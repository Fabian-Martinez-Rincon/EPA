# Herramientas

## R-info 2.9

El archivo [r-info-2.9.jar](r-info-2.9.jar) contiene el entorno utilizado para compilar y ejecutar los programas del robot.

Necesita una instalación de Java compatible. Luego puede abrirse el `.jar` desde el explorador de archivos o mediante:

```shell
java -jar r-info-2.9.jar
```

Las capturas de instalación se conservan en [Recursos/imagenes-generales](../Recursos/imagenes-generales).
