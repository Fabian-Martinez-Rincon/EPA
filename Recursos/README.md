# Recursos gráficos generales

- `examen-voluntario.png`: enunciado utilizado por los exámenes voluntarios (ver [Estudiantes](../Estudiantes/)).
- `imagenes-generales/`: capturas que explican cómo descargar Java y VS Code, instalar la extensión de R-info y trabajar con ambos entornos (ver [herramientas](../herramientas/)).

Las figuras que pertenecen a un capítulo específico del libro (diagramas de estructuras de control, recorridos, etc.) viven junto a ese capítulo en `conocimiento/unidad-NN-*/recursos/`, no acá, para mantener correctas sus rutas relativas y su trazabilidad por unidad.
