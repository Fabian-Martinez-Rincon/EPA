# Ejercicio 3: proceso rectángulo de base 5 y altura 3 en sentido horario

## Enunciado

Escriba un proceso que le permita al robot realizar un rectángulo de base 5 y altura 3 girando en la dirección de las agujas del reloj a partir de la posición (1,1).

## Datos

- **Entradas:** ninguna leída en tiempo de ejecución; el robot arranca en (1,1).
- **Salidas:** ninguna; el resultado se observa en el recorrido trazado (un rectángulo de 5x3 esquinas).
- **Restricciones:** el giro debe hacerse en sentido horario.
