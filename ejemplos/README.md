# Ejemplos de R-info

Programas breves para estudiar conceptos concretos antes de resolver la ejercitación completa.

- [Modularización](modularizacion): procesos, descomposición Top-Down y reutilización.
- [Parámetros de entrada](parametros-entrada): procesos configurables que reciben datos.
- [Parámetros de entrada/salida](parametros-entrada-salida): procesos que reciben y devuelven información modificada.

Se recomienda comparar primero los ejemplos sin parámetros con sus versiones parametrizadas y observar qué código deja de repetirse.
